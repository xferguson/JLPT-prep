# JLPT Prep — N5

An offline-first Progressive Web App for learning the Japanese on the JLPT N5:
kana, kanji, vocabulary, example sentences and grammar. It uses spaced repetition
(SRS), and progress is saved in the browser's `localStorage`, so it stays private
to each user and device.

No build step and no dependencies. It's plain HTML, CSS and ES modules.

## Running it

```sh
python3 -m http.server 8080      # or: npm start
# open http://localhost:8080
```

It has to be served over HTTP, because the service worker and `fetch` of the data
don't work from `file://`. Any static host works. For **GitHub Pages**, go to
Settings → Pages → *Deploy from a branch* → `main` / root. Once the page has
loaded, you can install it ("Add to Home Screen") and use it offline.

## What's included (N5)

| Data | Count | Source |
| --- | --- | --- |
| Kanji | 79 | N5 kanji from KANJIDIC2 via [kanji-data](https://github.com/davidluzgouveia/kanji-data) |
| Kana | 162 (reference chart, no cards) | all modern hiragana and katakana |
| Words & phrases | 713 | [open-anki-jlpt-decks](https://github.com/jamsinclair/open-anki-jlpt-decks) N5 list |
| Practice sentences | 1,913 (3–5 per word for 601 words) | Tatoeba / Tanaka corpus, via [jmdict-simplified](https://github.com/scriptin/jmdict-simplified) |
| Grammar patterns | 65 | written for this app (`scripts/grammar_n5.json`) |

Everything lives in `data/n5/*.json`, which is generated by `scripts/build_data.py`.

## How studying works

### 1. Kanji and kana words, most frequent first
Kana don't get cards of their own. You learn them through words, whose kana
stage tests the reading in kana. The Browse tab has a kana chart for reference.

The to-be-learned queue starts with two lists merged together:

- the 79 N5 kanji, ordered by how often they appear in about 26,000 real
  Japanese sentences
- the 573 words that need no N5 kanji (kana words, or words whose kanji are
  beyond N5), ordered by word frequency

The two lists are spread evenly through each other, so you meet a kanji about
every seven words, and each list keeps its own most-to-least-frequent order.

### 2. Learning sessions (Memrise-style)
A session teaches a small batch of new items (5 by default). Each item is shown
several times in different views, mixed in with the other items in the batch:

1. presentation (every form, the meaning and audio)
2. multiple choice: form → meaning
3. multiple choice: meaning → form
4. flashcard: recall, then rate yourself

A view you get wrong comes back later in the same session. New items are
brought in one at a time, and the next one only appears after the current
ones have had a couple of tests.

### 3. Reviews (Anki-style), with one view per review
Reviews use an SM-2 scheduler like Anki's: learning steps (10 min, 1 day),
graduation, ease factors, lapses and relearning. You recall the answer, reveal
it, and rate yourself **Again / Hard / Good / Easy**. Each button shows the
interval it will give you.

Each review tests the English meaning against **one** form. That form changes
as the card progresses:

| Item | Stages |
| --- | --- |
| kanji | meaning ↔ **romaji** reading → **kana** reading → **kanji** |
| word | meaning ↔ **romaji** → **kana** → **kanji** |

A *Good* or *Easy* answer moves the card to the next stage. The next review
marks it as "New form" and shows it as recognition first. After that,
reviews alternate between recognition (form → meaning) and recall
(meaning → form).

Some words use kanji that aren't N5 kanji, or are usually written in kana
(for example 椅子 and 居る). Those words finish at the kana stage, and the
written form is shown for reference.

### 4. Kanji unlock words
A kanji is **known** once it passes its first review at the kanji stage. At
that point, every word whose N5 kanji are all known (140 words need at least
one) goes to the **front** of the queue, so you learn it next. When several
words unlock at once, the most frequent comes first.

### 5. Words unlock cloze sentences (Clozemaster-style)
When a word passes its first review at its final stage, its 3–5 practice
sentences go to the front of the queue as **cloze** cards. Each card shows a
sentence with the word blanked out, plus the English translation. You answer
by multiple choice or by typing. Typed romaji is converted to kana as you
type. Then you rate yourself; the rating is pre-suggested from whether you got
it right.

Sentences are chosen to be as close to N5 as the corpus allows. Every
sentence is tokenised, and sentences where every content word is on the N5
list and every kanji appears in N5 vocabulary are preferred. Among those, shorter sentences come
first. Words used in conjugated forms are matched too (食べ**ました** counts
for 食べる). Furigana is shown over any kanji you haven't learned yet, and
sentences are tagged with the N5 grammar patterns they use.

### Stats
The **Stats** tab has a date range (7 / 30 / 90 days / all time) that applies
to every history chart on the page. It shows:

- **Totals**: kanji, words and sentences known, plus the success rate and
  review count for the chosen range.
- **What you've learned**: known items over time, one line each for kanji,
  words and sentences. A table below breaks each kind down into known /
  learning / unlocked / locked, and shows how many cards are at each form
  (romaji / kana / kanji).
- **Coming up**: reviews due each day for the next 14 days, split by kind,
  plus the next cards due and the size of the to-be-learned queue.
- **Reviews per day**: passed vs failed (Again) for each day.
- **Success rate**: broken down by item type and form (e.g. Words · Kanji),
  by card maturity (learning / young / mature, as in Anki), and by answer
  button.
- **Needs work**: the cards with the most lapses.

Every chart has a hover/keyboard tooltip and a "Show as table" view. Stats are
kept as small per-day counters inside the saved progress, not a log of every
review, so storage stays small.

### Other features
- **Browse**: kanji (plus a kana chart), words, sentences and grammar, with status
  (known / learning / queued / locked). Each item page shows its SRS state,
  what it's waiting on, and the words or sentences it unlocks.
- **Settings**: new items per day, session size, learning and relearning
  steps, cloze answer mode, furigana, and audio auto-play.
- **Audio** uses the device's Japanese text-to-speech.
- **Export / import** progress as JSON, for backup or moving to another
  device.
- **Keyboard shortcuts**: `space`/`enter` to reveal or continue, and `1`–`4`
  for answers and ratings.

## Development

```sh
npm test                          # unit tests (node:test, no dependencies)
pip install janome && npm run build-data   # rebuild data/n5 from the sources
python3 scripts/make_icons.py     # re-render icons (needs Pillow + a Japanese font)
```

```
index.html, manifest.webmanifest, sw.js   PWA shell + offline cache
css/app.css
js/app.js       screens, router, session UI
js/engine.js    queue, unlocking and review bookkeeping (pure, tested)
js/srs.js       Anki-style scheduler with stages (pure, tested)
js/session.js   Memrise-style learning session planner (pure, tested)
js/ui.js        rendering helpers (cards, furigana, multiple-choice options)
js/analytics.js aggregations for the Stats view (pure, tested)
js/charts.js    dependency-free SVG charts (stacked bars, lines, tooltips)
js/kana.js      kana ↔ romaji, answer normalisation, okurigana-aware furigana
js/store.js     localStorage persistence, export/import
data/n5/        generated course data
scripts/        data build pipeline, grammar source, icon renderer
```

The service worker fetches from the network first and falls back to its cache
when offline, so a new deploy shows up on the next load. Bump `VERSION` in
`sw.js` when you add or remove shipped files.

Progress is stored under the `localStorage` key `jlpt-prep:N5`, and the data
lives in `data/<level>/`. Adding N4 and higher later means building another
data folder and adding a level switcher.
